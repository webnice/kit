# Плагины

Пакеты в директории `plugin` содержат готовые компоненты приложения и генераторы подключения компонентов.

| Пакет | Назначение |
|---|---|
| `plugin/component` | Команда генерации файла импорта для автоматического подключения компонентов, модулей, моделей и иных частей приложения. |
| `plugin/component/bootstrap` | Bootstrap-компонент запуска приложения. |
| `plugin/component/configuration` | Компонент загрузки и подготовки конфигурации приложения. |
| `plugin/component/configuration/osext` | Расширения операционной системы для компонента конфигурации. |
| `plugin/component/environment` | Компонент окружения приложения. |
| `plugin/component/interrupt` | Компонент перехвата системных прерываний и перевода приложения в режим завершения. |
| `plugin/component/logger_console` | Компонент консольного логирования. |
| `plugin/component/logger_console/tpl` | Шаблоны вывода для консольного логирования. |
| `plugin/component/migration_sql` | Компонент применения SQL-миграций базы данных. |
| `plugin/component/pidfile` | Компонент PID-файла приложения. |
| `plugin/component/version` | Компонент версии приложения. |

Зарезервированные директории без Go-пакетов на текущий момент:

| Директория | Назначение |
|---|---|
| `plugin/component` | Место для компонентов приложения. |
| `plugin/controller` | Место для плагинов и контроллеров приложения. |
| `plugin/middleware` | Место для промежуточного (middleware). |
