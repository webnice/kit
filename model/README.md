# Модели данных

Пакеты в директории `model` содержат модели данных и генераторы моделей, используемые приложением на основе библиотеки.

| Пакет | Назначение |
|---|---|
| `model/fileinfo` | In-memory модель `os.FileInfo`: копирование метаданных файла, сеттеры/геттеры имени, размера, прав, времени модификации и системной информации. |
| `model/migration` | Модель версии SQL-миграций (`goose_db_version`) и получение текущей версии схемы базы данных. |
| `model/resource` | In-memory хранилище встраиваемых ресурсов: группы ресурсов, копирование при получении, формирование tar-архива группы. |
| `model/resource/embedder` | Команда генерации Go-файлов с встраиваемыми ресурсами из статических файлов и директорий. |
