# Модули

Пакеты в директории `module` содержат прикладные модули библиотеки: конфигурацию, HTTP-ответы, шину данных, работу с БД, логирование, файлами, изображениями, сигналами ОС и служебные инструменты.

| Пакет | Назначение |
|---|---|
| `module/ambry` | In-memory хранилище ключ/значение с поддержкой нескольких значений на ключ. |
| `module/ans` | «Единое окно» для HTTP API: загрузка тела запроса, JSON/XML-декодирование, верификация структур, формирование ответов и стандартных REST-ошибок. |
| `module/bus` | Внутрипроцессная шина данных: подписчики, синхронная и асинхронная публикация, worker-ы обработки сообщений. |
| `module/cfg` | Централизованная конфигурация приложения: bootstrap-конфигурация, загрузка конфигурации, пути приложения, gist-методы и регистрация компонентов. |
| `module/cfg/cli` | Модели и загрузка настроек командной строки и переменных окружения. |
| `module/cfg/cli/kong` | CLI-парсер на базе kong: команды, флаги, значения по умолчанию и help-вывод. |
| `module/cfg/cli/kong/repr` | Отладочное представление значений для CLI/help-вывода. |
| `module/cfg/const` | Внутренние константы модуля конфигурации. |
| `module/cfg/cpy` | Копирование конфигурационных структур с фильтрацией полей. |
| `module/cfg/reg` | Регистрация компонентов приложения в конфигурации. |
| `module/db/sql` | Подключение к SQL БД: пул соединений, DSN, обёртки `database/sql`, `gorm`, `sqlx`, применение миграций. |
| `module/db/sql/types` | Типы конфигурации подключения к SQL БД. |
| `module/dye` | ANSI-раскраска терминала: последовательности цветов, стилей, фона и сброса. |
| `module/dye/colorful` | Цветовые вычисления и преобразования: RGB, HSL, LAB, hex, палитры. |
| `module/dye/isatty` | Определение интерактивного терминала и Cygwin TTY. |
| `module/emt` | Работа с EML/MIME-телами сообщений: тело письма, файлы, изображения, функции встраивания ресурсов. |
| `module/file` | Информация о файлах и вычисление SHA-512. |
| `module/fmt` | Форматирование строковых значений, включая телефонные номера. |
| `module/img` | Обработка изображений и определение типов изображений. |
| `module/img/ico` | Декодирование и кодирование ICO-изображений. |
| `module/interrupt` | Перехват системных сигналов прерывания и вызов обработчика завершения приложения. |
| `module/lock` | Файловые блокировки. |
| `module/log` | Интерфейсы и обработчики логирования приложения. |
| `module/log/level` | Уровни логирования и их разбор из числовых/строковых значений. |
| `module/pdw` | Бассейн объектов-обёрток данных для шины данных (`module/bus`). |
| `module/rqvar` | Извлечение переменных HTTP-запроса из контекста, заголовков, cookie, URL, path-параметров и функций. |
| `module/server` | Управление HTTP-сервером приложения. |
| `module/tgbot` | Интеграция Telegram Bot API: конфигурация, обновления, цепочки обработчиков, пользователи Telegram. |
| `module/trace` | Получение краткого и полного стека вызовов. |
| `module/utility` | Общие утилиты, включая уникализацию срезов. |
| `module/uuid` | Работа с UUID-идентификаторами. |
| `module/wrwrap` | Обёртка `http.ResponseWriter` для контроля записи HTTP-ответа. |
